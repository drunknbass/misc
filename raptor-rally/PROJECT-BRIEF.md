# Raptor Rally — project brief

An original Unity keyboard arcade racer built around a miniature dirt stadium. Three stylized Raptor-inspired models share a four-truck, three-lap race: F-150 Raptor, Bronco Raptor and Ranger Raptor.

Coyote Basin is a 452 m switchback course with three hairpins, three main jumps, a low roller, striped barriers, stands and pit scenery. Off-course trucks can drive inward through barriers; returning to the course never grants checkpoint progress.

The game combines procedural 3D geometry, a reference-guided generated wheel image and an original editable Rive HUD. Camera modes show either the whole stadium or a close elevated view following the player.

The browser release has keyboard input, nitro, recovery, pause, reduced HUD motion, AI opponents and local best times. Touch/gamepad/hardware-wheel input, audio, multiplayer and online leaderboards are outside the current build.

Unity 6000.6.3f1 and official Web Build Support produce the GitHub Pages release. Source and locked dependencies are in `unity/`; asset provenance is documented beside the assets.
